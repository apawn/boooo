# 离线朗读

英语使用 Kokoro v1.0 的美式 Heart 女声（0.76 倍）。普通话默认使用晓晓，可在阅读页的「中文音色」中比较晓晓、晓伊和小贝的同句试听，并保存选择。这三个声音都使用同一完整精度模型、中文发音词典和 0.94 倍语速。试听音频使用与正文一致的合成配置生成。

首次克隆请运行 `git lfs pull`，再在 `__pages` 下运行 `npm ci` 和 `npm start`。中英文共用仓库随 Git LFS 分发的模型归档；首次启动校验并解压。安装完成后可离线使用。

服务启动时提前载入模型。已生成的片段按语言、音色和文字分别缓存，最多占用 16 MiB 内存，重启后清空。

[模型和音色说明](https://huggingface.co/hexgrad/Kokoro-82M)
