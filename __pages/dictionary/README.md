# 阅读器聚合词典

选中正文中的一个完整英文单词，自动打开浮动词典面板。支持键盘选词、跨词首加粗节点的选择、缩写和连字符。Esc 关闭面板，未固定时点击面板外或滚动正文也会关闭；选择整句和中文仍使用原有朗读。

## 词典内容

直接复用 [Saladict](https://github.com/crimx/ext-saladict) 开源项目的四套 **engine.ts、View.tsx 和样式**：

- 剑桥：仅显示英文释义和英文例句，保留英美音标及原站录音。
- Vocabulary.com：原站短释义、长解释；适配层补充该网站的英美音标和录音。
- 必应词典：音标、英美音、基本释义、词形、双语例句和例句录音。
- 有道词典：音标、原声、星级、词形、基础释义、柯林斯双解和权威例句。

四个来源并行查询，独立呈现和折叠；没有词条时内容区留空，网络错误显示重试及原站入口，不阻塞其他词典。缺失变形词条时尝试本地词库提供的原形。发音播放网站实际录音，**不会用 TTS 冒充词典英美音**。原正文朗读仍使用原来的本地 TTS。

页面选词后仅将单词发送到这些词典，不发送书籍、原句或阅读历史。请求通过本机服务转发，以适配普通网页无法直接跨域查词的限制。来源页和媒体地址有白名单、大小及超时限制，重定向逐次检查。第三方 HTML 清洗后才交给上游展示组件，不运行原站脚本，也不复制浏览器登录凭据。结果在内存中短暂缓存。

原站可能暂时不可用、需要验证或改变页面结构，此时可在面板打开原站；所有在线源失败则展开 ECDICT 本地兜底。部分单词没有双音标、双录音或例句，以原站实际提供的内容为准。

## 单词本

朗读提示栏右侧的“单词本”展开约 300px 侧栏，正文同步收窄。词典中的爱心收藏单词，并保存书籍、章节、段落和单词偏移；点击侧栏条目可跨章节返回原文并高亮单词，也可查词或取消收藏。每本书有自己的 `meta_data/book.json`（书籍信息、章节清单）和 `meta_data/words.json`（收藏单词、原文位置、收藏时间），均为可提交 Git 的普通文件。单词本只显示当前书的收藏；每次收藏或取消收藏都通过本机服务立即写入 `words.json`，服务端串行合并并原子替换文件，避免多个标签页互相覆盖。文件格式损坏时拒绝覆盖并提示错误。

旧浏览器收藏会在首次刷新后按原文地址迁入各书；没有来源信息的旧条目归入当前书、保留无位置状态。旧 localStorage 数据保留作为备份，迁移成功后不会重复导入。侧栏开关状态仍是浏览器偏好。收藏不上传第三方；Git 提交、推送需要另行执行。

顶部词典工具栏支持搜索、前后查询、查询历史、收藏及固定面板。

## 构建与运行

Node.js 22.13+（当前使用 24），首次安装本地词库还需要 Python 3。

```sh
cd __pages
npm install
npm run build:dictionary
npm run setup:dictionary
npm start
```

打包好的 `dictionary/saladict/bundle.js` 和 `.css` 随源码保存。修改适配层或更新上游后运行 `build:dictionary`。上游固定版本、文件来源及 MIT 许可见 `saladict/NOTICE.md` 和 `saladict/LICENSE`。保留了引擎、视图与样式；浮层外壳和扩展 API 适配是本项目实现，未集成沙拉查词的全部设置、生词本和翻译引擎。

## 离线兜底

### 词根资料子模块

`word_root/` 以 Git submodule 引入 `https://github.com/apawn/word_root.git`，已接入查词面板的“词根与词源”区块。首次克隆主仓库后，在仓库根目录执行：

```sh
git submodule update --init --recursive
```

`word_root/英语词根资料库/data/条目清单.json` 包含词根元数据、Markdown 路径及 `word_anchors` 单词锚点映射，可用于建立“单词 → 词族讲解”的本地反查索引。精讲正文在对应 Markdown 中；字段覆盖、来源和许可见子模块的 `英语词根资料库/覆盖与缺项.md` 与 `来源与许可.md`。主仓库固定子模块提交，不在安装或启动时自动更新远端版本。

查词优先精确匹配单词，再尝试 ECDICT 提供的原形；不会仅凭拼写猜词根。古典词根优先展示，可切换多个词族并展开逐词精讲。没有匹配时留空；子模块未初始化时显示可重试的提示，不影响其他词典。点击“完整词族”在当前书架服务中打开完整 Markdown，保留词条锚点、插图与来源链接。

服务端只加载轻量反查索引，正文按需读取并清洗 HTML，缓存最多 24 篇；浏览器按需加载所选词族的单词讲解。接口 `/dictionary/roots?word=...` 返回匹配，附 `id=...` 返回该词的精讲。`/dictionary/root-doc` 和 `/dictionary/root-asset` 仅允许访问子模块资料库内的 Markdown 与图片。该区块显示的中文讲解来自词根库，不改变剑桥纯英文显示。

### ECDICT

ECDICT 提供本地中文释义、英文释义和词形。数据库位于 `dictionary/data/ecdict.sqlite`，约 176 MB，不提交 Git；`npm run setup:dictionary` 从固定版本下载 CSV 并生成索引。已有数据库时跳过下载，缺失时不妨碍在线词典和阅读器运行。`npm start` 会先检查安装词库。

- ECDICT：https://github.com/skywind3000/ECDICT
- 数据版本：`39cfb9672c0906b63569e0453c2e6abfb9ab182a`
- 许可：MIT，见 `LICENSE-ECDICT`。

各词典的正文、图片和录音版权仍归原提供方；上游代码的开源许可不包含词典内容。本站只按用户选词获取，不把在线词典内容打包提交到仓库。

验证：`node --test dictionary/*.test.mjs reading-text.test.mjs`。

书架左下角“同步”按钮会提交整个仓库的本地修改（遵守 Git ignore），说明格式为 `同步书架 YYYY-MM-DD HH:mm:ss`（北京时间），作者固定为 apawn。随后 fetch 当前分支的 origin 上游、rebase、普通 push；没有本地修改时直接拉取和推送。页面显示当前步骤，也可展开同步详情。同步期间单词本暂停读写，已开始的保存会先完成。冲突时自动 abort 本次 rebase 并保留本地提交；网络/推送失败后可再次点击。不会强制推送，也不会自动提交子模块内部修改。GitHub HTTPS 使用本机已登录的 `gh` 凭据，服务仅监听本机地址。

正文选区不再自动打开词典：选区上方的工具条左侧用当前颜色标记，右侧色板提供黄、绿、蓝、粉、紫五种淡色及清除标记。悬停或点击词典按钮时才打开词典；整段选区会列出英文单词供进一步查询。重点保存在各书的 `meta_data/highlights.json`，采用章节、原文和选区位置恢复，绘制时不改动正文 DOM。顶部 `Highlights` 与单词本共用右侧面板，只显示当前选中的一种列表；支持跳回标记（含跨章节）及删除。点击 Sync 会一并同步这些 JSON。

### 与浏览器 Saladict 扩展共存

建议在扩展选项的 **Black/White List → Selection Blacklist** 添加正则 `^http://127\.0\.0\.1:4317(?:/|$)`，仅停用本地书架上的扩展划词与悬浮取词。这是浏览器扩展设置，不随 Git 同步。上游 `selection/index.ts` 在命中黑名单后将选词配置置空；`saladict-external` 类仅跳过部分选词流程，不能完整停用悬浮取词，因此未采用该内部类作为页面禁用开关。书架选区工具条同时忽略相同范围的重复选区事件，并使用捕获的选区进行查询，防止扩展重设选区导致首次悬停时词典被关闭。
