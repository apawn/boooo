# 阅读器聚合词典

选中正文中的一个完整英文单词，自动打开浮动词典面板。支持键盘选词、跨词首加粗节点的选择、缩写和连字符。Esc 关闭面板，未固定时点击面板外或滚动正文也会关闭；选择整句和中文仍使用原有朗读。

## 词典内容

直接复用 [Saladict](https://github.com/crimx/ext-saladict) 开源项目的四套 **engine.ts、View.tsx 和样式**：

- 剑桥：仅显示英文释义和英文例句，保留英美音标及原站录音。
- Vocabulary.com：原站短释义、长解释；适配层补充该网站的英美音标和录音。
- 必应词典：音标、英美音、基本释义、词形、双语例句和例句录音。
- 有道词典：音标、原声、星级、词形、基础释义、柯林斯双解和权威例句。

四个来源并行查询，独立呈现和折叠；没有词条时内容区留空，网络错误显示重试及原站入口，不阻塞其他词典。缺失变形词条时尝试本地词库提供的原形。发音播放网站实际录音，**不会用 TTS 冒充词典英美音**。原正文朗读仍使用原来的本地 TTS。

页面选词后仅将单词发送到这些词典，不发送书籍、原句或阅读历史。请求通过本机服务转发，以适配普通网页无法直接跨域查词的限制。来源页和媒体地址有白名单、大小及超时限制，重定向逐次检查。第三方 HTML 清洗后才交给上游展示组件，不运行原站脚本，也不复制浏览器登录凭据。结果在内存中短暂缓存。

原站可能暂时不可用、需要验证或改变页面结构，此时可在面板打开原站；所有在线源失败则展开 ECDICT 本地兜底。部分单词没有双音标、双录音或例句，以原站实际提供的内容为准。

## 单词本

朗读提示栏右侧的“单词本”展开约 300px 侧栏，正文同步收窄。词典中的爱心收藏单词，并保存书籍、章节、段落和单词偏移；点击侧栏条目可跨章节返回原文并高亮单词，也可查词或取消收藏。收藏及开关状态保存在当前浏览器的 localStorage，不上传服务器。旧字符串收藏保留，但没有原始位置；在当前章节能找到时可定位，否则提示没有找到位置。

顶部词典工具栏支持搜索、前后查询、查询历史、收藏及固定面板。

## 构建与运行

Node.js 22.13+（当前使用 24），首次安装本地词库还需要 Python 3。

```sh
cd __pages
npm install
npm run build:dictionary
npm run setup:dictionary
npm start
```

打包好的 `dictionary/saladict/bundle.js` 和 `.css` 随源码保存。修改适配层或更新上游后运行 `build:dictionary`。上游固定版本、文件来源及 MIT 许可见 `saladict/NOTICE.md` 和 `saladict/LICENSE`。保留了引擎、视图与样式；浮层外壳和扩展 API 适配是本项目实现，未集成沙拉查词的全部设置、生词本和翻译引擎。

## 离线兜底

ECDICT 提供本地中文释义、英文释义和词形。数据库位于 `dictionary/data/ecdict.sqlite`，约 176 MB，不提交 Git；`npm run setup:dictionary` 从固定版本下载 CSV 并生成索引。已有数据库时跳过下载，缺失时不妨碍在线词典和阅读器运行。`npm start` 会先检查安装词库。

- ECDICT：https://github.com/skywind3000/ECDICT
- 数据版本：`39cfb9672c0906b63569e0453c2e6abfb9ab182a`
- 许可：MIT，见 `LICENSE-ECDICT`。

各词典的正文、图片和录音版权仍归原提供方；上游代码的开源许可不包含词典内容。本站只按用户选词获取，不把在线词典内容打包提交到仓库。

验证：`node --test dictionary/*.test.mjs reading-text.test.mjs`。
