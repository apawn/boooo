## 海茵利希·布鲁希尔

| 年份 | 大事记 |
| --- | --- |
| 1899 | 1月29日出生在一个柏林的工人家庭<br>公立学校毕业后进入莱兴巴赫师范学校学习，但<br>未完成学业 |
| 1917 | 服兵役<br>士兵协会的成员，不久成为德国共产党党员 |
| 1918—1920 | 上柏林大学的晚间讲座课<br>一段时间内成为政治东西方新闻通讯社的职员 |
| 1924—1933 | 与作家兼作曲家罗伯特·基尔伯特合作搞小型歌<br>剧、轻歌剧和电影创作<br>与丽莎罗德·奥斯特瓦尔德结婚，不久离婚 |
| 1932 | 与娜塔丽·叶弗洛金结婚 |
| 1933 | 逃往布拉格 |
| 1934 | 到达巴黎 |
| 1936 | 与汉娜·阿伦特相识 |
| 1938 | 与娜塔丽·叶弗洛金离婚 |
| 1939 | 9月至12月被关押在法国集中营 |
| 1940 | 1月6日与汉娜·阿伦特结婚 |
| 1941 | <!-- 原书第579页 · PDF第621页 -->途经西班牙逃往里斯本，然后乘船去美国<br>5月到达纽约 |
| 1941—1951 | 战争期间在“民族意识委员会”做助理，并为马里<br>兰和普林斯顿的关于德国军事历史的军事训练课做<br>辅助工作 |
| 1950—1958 | 在纽约社会研究新校讲授艺术史和哲学 |
| 1952 | 8月7日获得美国国籍 |
| 1952—1968 | 任巴德学院的哲学教授 |
| 1961 | 6月与汉娜·阿伦特一起去巴塞尔拜访卡尔·雅斯<br>贝尔斯和格特鲁德女士（此行是布鲁希尔“二战”<br>后第一次去欧洲），1963年、1965年和1967年又<br>多次去雅斯贝尔斯家拜访 |
| 1969 | 夏天与汉娜·阿伦特一起去弗莱堡拜访马丁·海<br>德格尔及其夫人埃尔福丽德 |
| 1970 | 10月31日病逝于纽约 |
