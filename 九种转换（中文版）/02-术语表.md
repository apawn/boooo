# 引言 · 1.1 术语表

<sub>原书第 7–8 页</sub>

<!-- 原书第 7 页 -->

| 术语 | 含义 |
| --- | --- |
| `1突破, 1通道突破` | 通道走势的第一次突破。通常预计会失败并且是进入通道方向的信号 |
| `1趋势失败, 5 趋势失败` | 1 跳失败。价格比前一根k线高出 1 跳，触发了交易并止损。同样地 5tf, 9tf |
| `1PB` | 当日首次回撤或首次回撤发生在 1Rev后 |
| `1Rev` | 当日首次反转。另见 OR |
| `OR` | 开盘反转，趋势走势尝试后的反转，在第一小时。 |
| `1腿,2腿` | 1 腿的走势, 2 腿的走势 |
| `A2` | 在指数移动平均线附近第二次尝试反转回调移动。一次第二次失败的反转趋势尝试，因此是一个延续信号。如果离指数移动平均线太远，可能不符合作为一次2 |
| `A22` | 可能是因为第一个信号2, 需要较大的止损或存在较大的重叠，因此进行了第二次入场。需要较大的止损或存在较大的重叠。 |
| `H1` | 在一个下跌波动中，K线首次触及前一根K线的高点。反转下跌波动的第一次尝试。 |
| `fH1` | 价格跌破了给出H1, 的K线，从而未能成功。反转下跌波动的尝试。 |
| `fH1 MM` | 在强烈的下跌趋势中，如果给出H1 的k线及其前一根 k线（信号）较弱，那么失败的H1 很可能会给出衡量从下跌开始到失败的波动。 |
| `H2` | 在下跌波动中，k线第二次触及高于前一根k线在H1 和fH1之后 |
| `L1,fL1,L2` | H1,fH1,H2 的倒数，在上涨中。 |
| `MM` | 衡量移动。由于某些价格行为，预期会有1:1 的波动。例如，价格可能会在突破k线之上上涨2 点该k线长2 点。 |
| `BO` | 突破。价格已越过某种价格行为障碍，例如波动高点、指数移动平均线、趋势线等。 |

<!-- 原书第 8 页 -->

| 术语 | 含义 |
| --- | --- |
| `BP` | 突破回撤。价格经常回撤到被突破的价格行为屏障内。被突破的行为屏障。 |
| `fBO` | 突破失败。大多数首次突破尝试都会失败。 |
| `DP` | 在双底之后提供多头入场的回撤，或在双顶之后提供空头入场的回撤 |
| `WP` | 三腿回撤。这与A2类似 |
| `TL` | 趋势线。连接上涨趋势中的波动低点或下跌趋势中的波动高点的一条线。也可以是画到趋势线（TCL）的平行线。 |
| `TCL` | 一条连接上涨趋势中的波动高点或下跌趋势中的波动低点的线。也可以是画到趋势线（TL）的平行线。 |
| `G` | 缺口K线。下跌趋势中第一根K线，其高点低于指数移动平均线（ema）或上涨趋势中第一根K线，其低点高于指数移动平均线（ema）。如果这根K线是在下跌行情中看涨，是买入信号，反之亦然。 |
| `G2` | 如果缺口回补尝试失败，第二个缺口K线是缺口K线2。这是一个更高概率的交易。 |
| `i, o` | 内包k线，外包k线 |
| `ii` | 一个内包k线嵌套在另一个内包k线中（也称为iii依此类推） |
| `低低点，高高点` | 更低低点，更高高点 |
| `mW` | 微型楔形；一组k线构成的趋势线，而非波段交易 |
| `PB` | 回撤。 |
| `oio, ud` | 外内外套柱反转，上下柱反转，等等。 |
| `TTR` | 窄幅区间。重叠的价格波动，然后反转在超过之前的一两个跳之后来回移动尝试。 |
| `BW` | 带刺铁丝网。三根或更多水平k线，其中至少有一根是十字星。与TTR相似。 |
| `W` | 楔形。三次上涨，第三次上涨过冲了趋势通道线或至少触及它。一个反转信号使其成为W 反转 |
| `W1P` | 在新的方向入场的第一次回撤，发生于 W型反转 |
